# Contributing

Thanks for your interest in contributing to Medical Image Segmentation.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a virtual environment.
4. Install the requirements.
5. Make your changes.
6. Test the notebook or Flask application.
7. Open a pull request with a clear description.

## Guidelines

- Keep the repository structure simple.
- Prefer notebook-based experimentation for model work.
- Avoid adding unnecessary preprocessing or utility modules.
- Keep CPU and low-storage users in mind.
- Explain meaningful model or training changes.
- Do not commit downloaded datasets or large generated files.

## Pull Requests

A useful pull request should explain:

- What changed.
- Why it changed.
- How it was tested.
- Any limitations or follow-up work.
